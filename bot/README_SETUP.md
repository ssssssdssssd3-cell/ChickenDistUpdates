# 🤖 دليل تثبيت وتشغيل بوت الواتساب والمنيو السحابي للعملاء الجدد

مرحباً بك! هذا الدليل مُعدّ خصيصاً لمساعدتك في إعداد مشروع Firebase الخاص بالعميل وتسطيب البوت وربطه بالنظام في دقائق معدودة.

---

## 🛠️ أولاً: المتطلبات الأساسية على جهاز العميل
1. تحميل وتثبيت بيئة **[Node.js](https://nodejs.org/)** (الإصدار LTS الموصى به).
2. وجود متصفح **Google Chrome** مثبت على الجهاز.
3. اتصال إنترنت مستقر لتثبيت الحزم ورفع الملفات السحابية.

---

## ☁️ ثانياً: خطوات إعداد حساب Firebase للعميل

### 1. إنشاء المشروع:
* اذهب إلى منصة [Firebase Console](https://console.firebase.google.com/).
* اضغط على **Add project** (إضافة مشروع).
* اكتب اسم المشروع معبراً عن العميل (مثال: `albaraka-menu`).
* **تنبيه**: يفضل **تعطيل (Disable) Google Analytics** لتسريع الإنشاء وتفادي أي بطء.
* اضغط **Create project** ثم **Continue**.

### 2. تهيئة قاعدة البيانات Firestore Database:
* من القائمة الجانبية اليسرى، اضغط على **Build** ثم اختر **Firestore Database**.
* اضغط على **Create database**.
* اختر وضع الحماية: **Start in test mode** (البدء في وضع الاختبار).
* حدد موقع السيرفر الأقرب للعميل (مثلاً خوادم أوروبا).
* بعد اكتمال البناء، اذهب إلى تبويب **Rules** (القواعد) بالأعلى واستبدل الكود البرمجي بالصيغة التالية للسماح بربط البوت والمنيو:
  ```javascript
  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {
      match /{document=**} {
        allow read, write: if true;
      }
    }
  }
  ```
* اضغط على **Publish** (نشر).

### 3. تهيئة خدمة الاستضافة Firebase Hosting:
* من القائمة اليسرى تحت قائمة **Build**، اختر **Hosting**.
* اضغط على **Get started** وتجاوز المعالج بالضغط على **Next** حتى النهاية.

### 4. تسجيل التطبيق وجلب كود الإعدادات (Firebase Config):
* اضغط على أيقونة الترس بجانب Project Overview في الأعلى واختر **Project settings**.
* في تبويب **General** انزل للأسفل واضغط على زر الويب `</>`.
* اكتب اسماً للتطبيق وعلم خيار **Also set up Firebase Hosting for this app**.
* اضغط **Register app**.
* سيظهر لك كود الإعدادات، انسخ الأقواس وما بداخلها فقط (الـ JSON Object)، سيبدو بهذا الشكل:
  ```json
  {
    "apiKey": "AIzaSy...",
    "authDomain": "...",
    "projectId": "...",
    "storageBucket": "...",
    "messagingSenderId": "...",
    "appId": "...",
    "measurementId": "..."
  }
  ```

---

## 💻 ثالثاً: تهيئة ملفات البوت وتشغيله

1. فك ضغط ملف البوت في جهاز العميل (يجب أن يكون المجلد باسم `bot` وبجوار ملف تشغيل البرنامج الرئيسي `ChickenDist.exe`).
2. داخل مجلد `bot`، قم بإنشاء ملف نصي جديد باسم **`firebase_config.json`**.
3. افتح الملف والصق داخله كود الإعدادات (Config) الذي نسخته في الخطوة السابقة واحفظه.
4. افتح ملف **`.firebaserc`** الموجود بمجلد البوت واكتب معرف مشروع العميل الجديد بدلاً من الافتراضي:
   ```json
   {
     "projects": {
       "default": "معرف_مشروع_العميل_هنا"
     }
   }
   ```

---

## ⚡ رابعاً: تثبيت ورفع صفحات الويب سحابياً

افتح نافذة الأوامر (CMD) داخل مجلد `bot` ونفذ الأوامر التالية بالترتيب:

### 1. تثبيت حزم تشغيل البوت محلياً:
```bash
npm install
```

### 2. تثبيت أداة Firebase للرفع السحابي (مرة واحدة فقط على الكمبيوتر):
```bash
npm install -g firebase-tools
```

### 3. تسجيل الدخول لحساب Firebase:
```bash
firebase login
```
*(ستفتح لك صفحة في المتصفح، اختر حساب الجيميل الخاص بالمشروع واضغط Allow).*

### 4. رفع وتفعيل صفحات المنيو ولوحة المحاسب سحابياً:
```bash
firebase deploy --only hosting
```
*(بعد انتهاء الرفع، سيظهر لك الرابط النهائي للموقع السحابي للعميل).*

---

## 🚀 خامساً: تشغيل البوت والربط مع الكاشير

1. لتشغيل البوت، نفذ هذا الأمر في CMD داخل مجلد `bot`:
   ```bash
   npm start
   ```
2. افتح برنامج المبيعات الرئيسي `ChickenDist.exe` واذهب إلى شاشة **إدارة البوت واللوحة السحابية**.
3. ستلاحظ أن روابط المنيو السحابية وتطبيق المحاسب تغيرت تلقائياً لرابط العميل الجديد!
4. اضغط على **"ربط وتفعيل البوت"** لتبدأ الخدمة ومسح رمز الـ QR بالهاتف لتفعيل رقم الواتساب.

---
**💡 نصيحة تقنية**: يمكنك استخدام برنامج مثل **PM2** أو إنشاء سكربت بادئ تشغيل (Startup Shortcut) ليعمل البوت تلقائياً عند إقلاع نظام التشغيل.
